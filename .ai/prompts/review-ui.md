# Prompt - Revisar UI Frontend

Revise a tela considerando padrões de UI/UX do projeto.

## Verificar

- A tela está clara?
- Tem loading?
- Tem empty state?
- Tem mensagem de erro?
- A ação principal está visível?
- Há botões demais?
- Component está grande demais?
- Há duplicação de componentes?
- O service está sendo usado corretamente?
- HttpClient foi usado indevidamente em component?

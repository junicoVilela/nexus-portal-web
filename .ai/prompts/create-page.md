# Prompt - Criar Página Frontend

Crie uma página Angular para a feature informada.

## A página deve ter

- título
- subtítulo quando útil
- loading state
- empty state se for listagem
- tratamento de erro
- chamada ao service
- HTML limpo
- TypeScript organizado

## Regras

- Component não deve conter regra de negócio pesada.
- Component não deve montar URLs de API.
- Component deve usar service da feature.

# Prompt - Criar Service Frontend

Crie um service Angular para comunicação com API.

## Regras

- Usar HttpClient.
- Retornar Observable.
- Usar environment.apiUrl.
- Criar métodos claros: listar, buscarPorId, criar, atualizar, excluir.
- Não tratar regra visual no service.
- Tipar request e response.
